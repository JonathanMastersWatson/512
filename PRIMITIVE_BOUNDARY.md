# Primitive Boundary

512 defines constraint behaviour at the execution boundary.

It does not define:

- system architecture
- orchestration
- deployment models
- implementation patterns

Any system built using 512 as a primitive is a derivative implementation.

Responsibility for design, deployment, and operation of that derivative
remains entirely with the implementing party.

---

*This file defines the boundary of the 512 primitive. It does not
modify the canonical kernel, the seven invariants, or the canonical
SPEC_HASH.*
