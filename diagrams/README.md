# Diagrams

This folder contains canonical Mermaid diagrams for the 512 Commit Gate.

These are topology artifacts, not marketing visuals.

They must remain deterministic, versionable, and machine-readable.

## Files

- `TOPOLOGY.md` — boundary position, conformant model, non-conformant patterns
- `SEQUENCE.md` — validation sequence, fail-open mechanics, early-exit evaluation
- `INVARIANTS.md` — K1–K7 evaluation order, proxy mapping, early-exit flow
- `LAYERS.md` — architectural layer stack

## Normative Authority

`512_ARCHITECTURE_v3.4.md` · `512_IMPLEMENTATION_v3.3.md`

Diagrams reflect the canonical architecture. Where a diagram and a
canonical document conflict, the canonical document governs.
